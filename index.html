Crear tu caja fuerte

Define una contraseña larga que puedas recordar. Se usa para cifrar los documentos en este dispositivo.

Al crearla recibirás un código de recuperación. Con él podrás definir una contraseña nueva si olvidas la actual.

Desbloquear caja fuerte

Introduce la contraseña para descifrar los documentos guardados en este dispositivo.

Recuperar acceso

Escribe tu código de recuperación de 32 caracteres y elige una contraseña nueva. Tus documentos se conservan.

Esta caja fuerte se creó con una versión anterior, sin código de recuperación. Si recuerdas la contraseña, desbloquéala una vez y MiVault generará tu código automáticamente.

No tengo el código de recuperación

Sin la contraseña ni el código, nadie puede descifrar los documentos, tampoco MiVault. La única salida es borrar esta caja fuerte, crear una nueva y restaurar un respaldo .dsafe si tienes uno (con su propia contraseña).

Tu código de recuperación

  • Guárdalo fuera de este teléfono: impreso, en un gestor de contraseñas o con una persona de confianza.
  • Quien tenga este código y acceso a tu dispositivo puede abrir la caja fuerte. Trátalo como una llave.
  • Al usarlo, MiVault genera uno nuevo y el anterior deja de funcionar.
